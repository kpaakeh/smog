# Smog

Fabric-мод для Minecraft **26.3**, Fabric API **0.161.0+26.3**, Java **25**.

Текущий этап — **медная мастерская 0.7.0**: керамика, литьё меди/олова/бронзы, меха и печь обжига. Очаг и печь используют общую систему комплексных мультиблоков переменного размера со сменными функциональными частями. Старые электрические машины и генераторы остаются только тестовыми демонстрациями.

Как начать и построить: [COPPER_AGE_IMPLEMENTATION.md](docs/COPPER_AGE_IMPLEMENTATION.md). Правила комплексных сооружений: [COMPLEX_MULTIBLOCKS.md](docs/COMPLEX_MULTIBLOCKS.md).

- **13 руд:** олово, цинк, свинец, никель, боксит, марганец, хром, титан, вольфрам, молибден, уран, литий, редкоземельная руда.
- **7 неметаллических залежей:** известняк, доломит, каолин, каменная соль, флюорит, фосфорит, графит. Сера используется ванильная.
- **2 подземных ресурса:** нефть и минерализованный рассол.
- Сохранены обработанные материалы, теги, текстуры, сборка ресурсных данных и общие API.

Все руды генерируются небольшими ванильными жилами с отдельными диапазонами высот и пиками частоты; пласты пород и резервуары имеют шумные границы. Уран обязателен: атомная энергетика запланирована.

Какие текстуры рисовать: [TEXTURES.md](docs/TEXTURES.md).
Параметры генерации и формы сырья: [RESOURCES.md](docs/RESOURCES.md).
Сохранённые системы: [FOUNDATIONS.md](docs/FOUNDATIONS.md), [INDUSTRY.md](docs/INDUSTRY.md).
Проверки и изолированные демонстрации: [TESTING.md](docs/TESTING.md).

## Сборка

```powershell
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-25.0.4'
.\gradlew.bat build
.\gradlew.bat runClient -PwithJei
```

Готовый файл: `build/libs/smog-0.7.0.jar`. `-PwithJei` включает JEI в dev-клиенте.
На Linux/macOS используйте `sh ./gradlew build`. Первая сборка требует интернета.

Каталог: `src/main/content/smog.content.json`. Namespace: `smog`, Java-пакет: `io.github.kpaakeh.smog`.
Текстуры лежат в `src/main/resources/assets/smog/textures`; обычная сборка не требует Python или платных сервисов. Скрипты создания отсутствующих ассетов сохраняют существующие PNG.

Встроена Team Reborn Energy 5.0.0. Код FE, проводов, GUI, обработки, жидкостей, зон и мультиблоков сохранён. Демонстрационные регистрации и их арт находятся только в тестовом моде `src/gametest`, который не включается в основной JAR.
