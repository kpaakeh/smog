# Smog

Smog — технический мод о развитии мастерской от ручного литья до промышленности будущих эпох.

## Что добавляет мод

- Плавильню со сменными узлами, расплавленными металлами и получением сплавов прямо в мире.
- Литейные столы, формы и желоба для отливки деталей и инструментов.
- Составные инструменты: выбирай материал головки, рукоять и крепление, ремонтируй и заменяй части.
- Керамическую мастерскую с формованием, обжигом и огнеупорной кладкой.
- Промывку медного сырья и ручной пресс для масла и растительных волокон.
- Водоснабжение с насосом, резервуарами, трубами и кранами.
- Грузовую тележку, погрузочный кран и лебёдочную переправу для грузов и поездок игрока.
- Новые руды, каменные породы, нефть и минерализованный рассол.
- Рецепты и схемы мастерской в JEI.

## Установка

Minecraft **26.3**, Fabric Loader **0.20.1+**, Fabric API **0.161.0+26.3**, Java **25**.

Скачай [последний релиз](https://github.com/kpaakeh/smog/releases/latest) и положи JAR в папку `mods` вместе с Fabric API. Team Reborn Energy уже встроена. Для рецептов и схем установи JEI.
