# Отложенный прототип двух клиентов

Пользователь отложил сетевую приёмку. Текстовые исходники сохранены для следующего отдельного задания; они не компилируются и не запускаются обычной сборкой.

Первый вариант ProcessHandle не смог получить Java arguments на Windows. Последний прототип заменяет это явным Gradle manifest JavaExec/Loom и отдельным Java argfile с абсолютными путями. Host должен создать тестовый пол, отключить аутентификацию только у временного сервера и запустить peer с отдельными gameDir/UUID и heap1G. Запуск прерван пользователем до создания peer; рабочий прогон двух клиентов НЕ подтверждён. JVM host27784 завершён, дочерний peer не запускался.

При возобновлении сначала нужны проверка manifest, совместимость игрового подключения и реальная приёмка фаз/выхода/отключения. Снимки и server mocks из других сценариев не доказывают сетевую работу двух клиентов.
