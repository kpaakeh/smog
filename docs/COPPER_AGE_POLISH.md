# Сверка медной мастерской — 0.10.5

Документация перечитана и сопоставлена с существующим кодом: COPPER_AGE_DESIGN (пункты 1–43), COPPER_AGE_TOOLS_AND_CRAFTS (1–27), MODULAR_WORKSHOP_REFERENCE, SMELTERY_GUIDE, TOOL_MATERIALS, COMPLEX_MULTIBLOCKS, ITEM_MODELS, TEXTURES. Отдельный read-only ревьюер проверил процессы и сохранность. Это сверка реализации, а не отчёт об игровом прохождении.

## Приоритет решений

Последние указания пользователя уточняют первоначальные примеры: плавильня полая, от 3 до 11 по каждой оси, без внутреннего тигля и малого плавителя; порты необязательны, вставки вне углов/рёбер. В GUI нет переливания. Модульная кладка сохраняет родные модели. Кран увеличен до 5 × 5 × 5. Журнал исследователя удалён целиком, включая рецепт, достижение, текстуру и старый относящийся к нему тест.

| Требование документации | Реализация и доводка |
|---|---|
| Ваниль сохраняется; обычная медь подходит | Канонические ванильные слитки, явные теги; старые ванильные рецепты не заменены |

| Материал ограничен условиями | MetalProcessing: корпус, футеровка, закрытая камера, среда и перегрев; теперь отдельные короткие причины отказа |

| Сплавы из совместных жидкостей | Автоматическое сплавление с проверкой топлива/нагрева/совместимости; кнопка смешивания не требуется |
| Меха помогают партии | Конечный запас усиления, без увеличения выхода металла; совместимый бронзовый привод |
| Формы многоразовые/одноразовые по технологии | Керамические, песчаные и золотые варианты; образец сохраняется, оснастка закреплена до конца операции |

| Литьё видно в мире | Слои в камере, струи, заполненная форма и готовые предметы; пользовательские модели краника сохранены |
| Информация в GUI соответствует процессу | Литейный стол/ёмкость показывают реальный объём, фазу и оставшееся охлаждение; прогрев печи не подменяет эти стадии |
| Обжиг партиями | Обычный обжиг остаётся; специальная печь обрабатывает керамику. Заполненный выход не запускает новое топливо, размер партии учитывает свободное место |
| Гончарный стол удобен сериями | Выбор изделия и партии до восьми; партия уменьшается по свободному выходу вместо отказа при частично занятом слоте |

| Пресс полезен хозяйству | Масляная/волокнистая корзины, масло/жмых/волокно, очередь партий; отсутствие жидкости и свободного выхода останавливает расход |

| Инструмент определяется частями | Отдельный JSON каждого материала, независимые роли, сохранённая схема и общие окрашиваемые маски |
| Изношенную головку можно понять до сборки | На самой снятой головке виден остаток ресурса и полоса износа; чары и износ продолжают принадлежать головке |

## Границы концепции

Поздняя броня, площадные инструменты, редкие художественные мотивы, специальные контролируемые среды и расширенное рабочее место в исходных документах описаны как дальнейшие/неутверждённые варианты. Они не объявлены реализованными этой полировкой. Открытый ранний корпус не превращён в установку для всех химических и поздних процессов. Журнал исключён последним прямым решением пользователя.

Числа длительности и баланса в исходном дизайне были предложением, а не измеренным прохождением. Компиляция и упаковка выполняются с исключённым check. Тесты, игровые проверки и генераторы рисунков не запускаются по указанию пользователя; графику, ввод и длительность первого прохождения необходимо оценивать в клиенте.
