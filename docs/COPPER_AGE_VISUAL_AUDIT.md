# Медная мастерская: визуальная сверка, 1 ноября 2026

> Актуальный контракт 0.0.4: [единый статус Медной мастерской](COPPER_WORKSHOP_STATUS.md). Последние прямые указания пользователя важнее ранних примеров ниже. Десять инструментов, один обычный стержень, любые материалы подходящих деталей; уникальные свойства материалов сохранены, слотов улучшений нет. Стол керамиста работает через GUI с расходом при получении результата; промывка имеет восемь процессов. Подробности: [JEI](JEI_WORKSHOP_EXAMPLES.md), [керамика](POTTERY_GUIDE.md), [промывка](WASHING_WORKSHOP.md). Датированные старые числа тестов и фразы об ожидающих проверках описывают прошлую ревизию, а не текущий долг. Новые результаты фиксируются в MODLOG.md.
>
> Пользователь исключил длительное survival-прохождение/замеры времени, перенос старых миров и проверку своего модпака из этой приёмки. Финальный milestone эры и новые механизмы отложены. Реальный многопользовательский прогон и визуальные проверки нельзя объявлять завершёнными по одному серверному тесту.

Проверка сопоставляет текущую реализацию с `SMELTERY_GUIDE.md`, `COMPLEX_MULTIBLOCKS.md`, `MODULAR_WORKSHOP_REFERENCE.md`, `COPPER_AGE_DESIGN.md`, `COPPER_AGE_TOOLS_AND_CRAFTS.md`, `TEXTURES.md` и `ITEM_MODELS.md`. Референс Tinkers Construct понимается как читаемая мастерская, видимое литьё и составные инструменты. Он не отменяет последних решений: без малого плавителя, внутреннего тигля, переливания через GUI и полевого журнала.

«В коде» означает подтверждённый путь реализации, а не пройденную визуальную приёмку. «Требует кадра» означает, что форму, контраст, перекрытия или понятность ещё нужно оценить в клиенте. Старые отчёты о скриншотах не считаются проверкой этой ревизии.

## Выполненные статические проверки

- `python tools/audit_textures.py`: 552 PNG, 0 неиспользуемых, 0 отсутствующих, 0 отсутствующих моделей. Исправлен crash на современных texture objects `{sprite, force_translucent}`; аудит учитывает исходные overrides.
- `python tools/audit_models.py`: 62 модели, 5972 грани, 0 ошибок. Исправлена интерпретация atlas 32/64 px и сравнение плоскостей: разные повороты не считаются одной локальной плоскостью, противоположные внутренние грани не считаются наружным z-fighting. Это ограниченная статическая проверка: пересечения разных преобразованных мешей она не доказывает и не исключает.
- Найден и удалён нулевой по толщине элемент тележки `[6,3,-4] → [6,5,16]`, дублировавший поверхности пола/колеса. Остальные вершины, UV, display transforms и PNG сохранены.

Добавлен клиентский `ToolPreviewDetails`: наведение на строку ресурса `[?]` показывает назначение по рабочим головкам, уровень добычи каждой головки и численное сравнение головок с собранным инструментом. Для нескольких головок база ресурса — округлённое среднее, база максимальной скорости — самая быстрая добывающая головка. Итоговый ресурс и максимальная скорость читаются из фактических компонентов результата; проценты показывают разницу. Чары и ситуативные свойства явно исключены из постоянных показателей. Обычная подсказка самого предмета сохранена отдельно. Во время серийной работы строка показывает оставшееся количество; дополнительной строки или расширения окна нет.

Уникальные свойства обязательны по новому решению пользователя; слоты улучшений не нужны и не считаются незакрытым требованием. Новые подсказки, очередь и стержневое литьё не компилировались и не просматривались в клиенте: сборка ожидает команды.
