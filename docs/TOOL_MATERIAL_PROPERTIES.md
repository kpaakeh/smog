# Поведенческие свойства ранних материалов — 0.0.4

> Навигация 0.0.4: [полное руководство](GUIDE_0.0.4.md) · [точные данные каталога](CONTENT_REFERENCE_0.0.4.md) · [все JSON-рецепты](RECIPE_REFERENCE_0.0.4.md) · [оглавление](README.md). Датированные результаты проверок ниже относятся к своим ревизиям.

Свойства берутся из профиля конкретной части. Они не повышают уровень добычи, не создают руду и не используют слоты улучшений. Свойство головки действует только на подходящие для него действия.

| Материал / часть | Поведение | Ограничения |
|---|---|---|
| Дерево / головка | Вспаханная деревянной мотыгой почва сразу увлажнена | Обычное последующее высыхание; нужна успешная штатная вспашка |
| Камень / головка | Удар отталкивает существо | Перерыв 40 тиков; без дополнительного урона и PvP-эффекта |
| Медь / головка | Непрерывная подходящая добыча накапливает наклёп | До 4 ступеней по 4%; сброс после 100 тиков простоя |
| Железо / головка | После подходящей добычи притягивает свободные предметы в радиусе 2,5 блока | 40 тиков; только рабочий инструмент в руке; учитываются задержка подбора и доступный владелец броска; штатный подбор и количество предметов не меняются |
| Олово / головка | Удар тушит горящее существо | Перерыв 40 тиков, только при реальном тушении; PvP исключён |
| Свинец / головка | Удар ненадолго ослабляет существо | Слабость 30 тиков, перерыв 100 тиков; PvP исключён |
| Бронза / головка | Удар замедляет существо | Длительность/перерыв задаются существующим профилем; PvP исключён |
| Золото / головка | Удар помечает существо свечением | Длительность/перерыв задаются существующим профилем; PvP исключён |
| Верёвка / крепление | Каждое шестое подходящее рабочее действие не расходует износ | Общий механизм хватки; существующий износ не восстанавливается |
| Кожа / обмотка | Каждое четвёртое подходящее рабочее действие не расходует износ | При сочетании хваток действует более сильная, без сложения бесплатных действий |
| Растительное волокно / обмотка | Подходящая добыча под водой возвращает 4 единицы воздуха | Не выше максимального запаса воздуха |
| Шерсть / обмотка | Инструмент в руке уменьшает накопленное замерзание | Только пригодная к работе сборка; хранение в инвентаре и сломанная головка эффекта не дают |

Кулдауны боевых свойств сохраняются на частях при разборке и повторной сборке. Магнетизм не обходит штатный подбор или вместимость инвентаря. Звук и живой сетевой прогон пользователь отложил; серверные проверки не выдаются за проверку сетевых задержек.
