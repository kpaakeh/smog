# Транспорт и общие правила — сверка 1 ноября 2026

Приоритет: PROJECT_DECISIONS и актуальные LOADING_CRANE/WINCH_ROPEWAY выше старых размеров в первоначальном дизайне. Идеи из COPPER_AGE_ADDITIONAL_MECHANISMS отдельно названы предложениями, а не готовым обязательным каталогом.

| Требование | Реализация / проверка | Итог |
|---|---|---|
| Тележка полезнее одного сундука, без новой системы веса | HandcartEntity: 54 настоящих слота, штатное меню, наследуемое сохранение контейнера | Серверная регрессия последнего слота/меню проходит |
| Ручная тяга, без топлива | Shift+ПКМ закрепляет одного тянущего; расстояние/смерть/спектатор освобождают | Код; длительное движение по рельефу не измерено |
| Кран фиксированный 5×5×5 | Определение loading_crane, отдельные балки/опоры, реальные позиции A/B | Прежний размер отменён последними решениями |
| Конечная партия, направление, редстоун | LoadingCrane: до стака; фронт сигнала запускает один заказ | Регрессии ручного цикла и постоянного сигнала |
| Нельзя менять направление с грузом | CopperInteractions блокирует ручное переключение; CopperWorkshops теперь отклоняет чужие pottery-кнопки | Исправлен серверный обход через menu-button |
| Реальная траектория, остановка без потери | obstruction проверяет загруженную область; груз хранится в слоте 1 | Регрессии заполненного получателя и препятствия |
| Неполная сборка понятна | Фиксированные медные структуры теперь записывают координаты первого неправильного блока; overlap отдельно | Исправлено; JEI показывает требуемый состав |
| Поворот сохраняет возможности | bay и obstruction используют rotation контроллера; грузовой кран нельзя повернуть занятым | Код; все четыре ориентации не сняты на кадрах |
| Поломка контроллера возвращает груз | Сохранённый инвентарь MachineEntity, стандартный drop контейнера | Код; существующие регрессии сохранности |
| Без принудительной загрузки | cargo/obstruction/ropeway проверяют чанки, пассажирская посадка перебирает только getChunkNow | Код |
| Канат до 24 блоков с провисанием | Ropeway.clear и Ropeway.point, взаимная связь анкеров | Серверные тесты разрыва/починки и доставки |
| Посадка палкой, в том числе в середине | Авторитетный луч взаимодействия, проверка дальности и препятствий | Серверные тесты видимого/дальнего/закрытого каната |
| Пассажир и груз не пересекаются | busy резервирует линию, queued/слот груза запрещают посадку | Серверная регрессия |
| Безопасная высадка и разворот | Поиск площадки, остановка у препятствия, направление взглядом | Серверные сценарии; текущие пользовательские изменения сохранены |
| Грузовые ящики из старой концепции | Используются совместимые ванильные контейнеры и тележка | Отдельный специальный ящик не требуется выбранным основным действием |
| Шахтный ворот, люлька, толчея и прочее дополнение | Файл явно не является поручением реализовывать предложения | Не добавлялись под видом полировки |

Непроверенное нельзя считать закрытым: длительное прохождение с добычей и строительство двора в survival, движение тележки по разнообразному рельефу, многопользовательские задержки и выгрузка чанков реальными клиентами. Изолированные тесты проверяют конкретные инварианты, но не доказывают целевую продолжительность 3–5 часов.
