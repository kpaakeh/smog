# Матрица визуальной проверки 0.0.4

Отдельная сцена `runClientGameTest -PvisualReviewTest` создаёт одноразовый мир и работает через Fabric test API без ввода в рабочий стол. Само наличие сцены не означает, что она завершилась или что все кадры просмотрены. Конкретный результат запуска и просмотра добавляет основной агент.

| Проверка | Имена кадров | Основание/ограничение |
|---|---|---|
| Плавильня3×3×3 с четырёх сторон | `visual-smeltery-3-north/east/south/west` | Настоящая собранная полая оболочка, стекло и три слоя металла |
| Плавильня11×11×11 с четырёх сторон | `visual-smeltery-11-north/east/south/west` | Предельный размер, реальная ёмкость, без растянутой общей модели |
| Вода рядом со стеклом и металлами в сумерках | `visual-glass-water-metals-dusk` | Закрытый ванильный водяной столб рядом с прозрачной оболочкой; проверяется порядок прозрачности |
| Жидкость сбоку топливного бака | `visual-fuel-tank-liquid-sides` | Пылающее топливо на6/8ёмкости, объёмный слой |
| Прямой слив и слив через желоб | `visual-flow-direct-and-channel` | Два настоящих порта, открытые краны, два получателя; сцена требует фактический приём металла |
| Состояния литейного стола | `visual-casting-empty/partial-hot/cooling/ready` | Настоящая вставка4500+4500единиц меди, ручные процессные тики и проверка готового слитка |
| Кран: захват, подъём, перемещение, разгрузка | `visual-crane-start/pickup/raised-travel/delivery/finished` | Нормальный серверный заказ64предметов, отдельная проверка доставки |

Исправлены два конкретных несоответствия renderer: предметы на медной наковальне были подняты до старой высоты стола1,02–1,06 вместо поверхности новой модели; начальная неполная заливка ошибочно рисовалась как холодная до запуска охлаждения. Высота снижена до0,9/0,925, расплав остаётся ярким на стадиях заливки и охлаждения. Новые текстуры машин для этого не создавались.

Текстуры инструментов отдельно собраны в `build/review/2026-11-02/visual-review/tool-parts-contact.png`: формы головок, сборка с обычным деревянным стержнем, отливки, керамика и нейтральные маски оснастки. Контактный лист просмотрен: очевидных разрывов стыка не видно, три клинка имеют разные силуэты; авторские PNG массово не перегенерировались. Это не заменяет просмотр каждого материала в руке.

Проверка звука и живого мультиплеера отложена последним указанием пользователя. Указанные кадры не доказывают их готовность и не являются продолжительным survival-прохождением.
