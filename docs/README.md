## Правила актуализации

Версия остаётся 0.0.4. Изменение кода, ресурсов или генератора требует пересверки справочников. Снимок производственного каталога не включает тестовые промышленные регистрации. Число записей каталога не равно числу блоков в игре: семейства и детали разворачиваются генератором, а часть механик реализована кодом. Файлы старого дизайна сохранены для истории; их идеи не являются автоматическим поручением добавлять содержимое.
