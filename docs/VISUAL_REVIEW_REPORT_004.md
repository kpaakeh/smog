## Конкретные находки

1. **P1 — неоднозначное состояние и отсутствующая команда запуска пресса.** `0011_copper-press-gui.png`: во входе 16 семян, выход пуст, отображаются «Готово» и «Партии: 0», кнопка запуска на кадре отсутствует. Игроку неясно, почему работа не идёт. При пустой очереди корректнее «Ожидает запуска» с видимой доступной кнопкой. Основной агент сообщил, что нашёл ошибку видимости общей кнопки craft и исправляет её; исправленная версия ревьюером ещё не просмотрена.
2. **P2 — обрезана необходимая часть объёма отливки.** `0036_copper-casting-partial-gui.png` и `0040_copper-casting-core-partial-gui.png`: строка «Залито: 4 1/2 самородка / 1 …» / «Залито: 2 1/4 самородка / 4 …» теряет требуемый объём. Нужны две строки либо компактный вид с полным значением в тултипе. Основной агент сообщил об исправлении; новый кадр ещё не просмотрен.
3. **P2, риск для проверки — высота раскрытого тултипа.** `0015_copper-tool-tooltip-properties.png`: Ctrl-вид занимает около 178 GUI-пикселей по высоте на кадре 854×480, scale2. При том же окне scale3 доступно лишь160 GUI-пикселей. На таком масштабе возможна потеря строк. Это прогноз по геометрии, не доказанный баг масштаба3. Следует сначала удалять лишние пустые строки/памятку, сохраняя свойства. Обязательна новая матрица масштабов.
4. **P3 — разное обозначение единиц в одном окне.** `0031_copper-reservoir-oil-gui.png`: точный объём использует `mB`, строка скорости — `мВ/с`. Желательно выбрать одно обозначение для жидкости во всём интерфейсе.
