# Проверки надёжности мастерской

Уточнение объёма по запросу пользователя: длительное прохождение, измерение его времени, перенос старых миров и проверка всего пользовательского модпака не входят в этот проход. Проверки текущего сохранения операций нужны для сохранности предметов и не являются переносом старого мира.

| Сценарий | Автоматическая проверка | Что она не доказывает |
|---|---|---|
| Два открытых меню плавильни | `WorkshopReliabilityTests.smelteryPagesBelongToEachViewerAndStructureChangeInvalidatesBoth`: независимые страницы двух серверных игроков, закрытие доступа после разборки структуры | Сетевые задержки двух удалённых клиентов и визуальная синхронизация |
| Получение общего готового выхода | `twoViewersCannotReceiveTheSameFinishedCastingStack`: два последовательных авторитетных запроса, отсутствие дублирования, закрытие меню с сохранением предметов | Поведение каждого стороннего контейнерного мода |
| Общая керамическая мастерская | Существующие `PotteryTests`: два выбора, актуальный вход, занятые назначения, отсутствие бесплатного предпросмотра в ItemStorage | Реальная задержка сети и действия через сторонний клиент |
| Освобождение тележки | `cartReleasesAbsentAndDistantPullersWithoutLosingSavedCargo`: отсутствующий игрок, разрыв дальности, текущее сохранение последнего грузового слота | Обрыв TCP-соединения во время реальной поездки и все позы анимации |
| Неровности дороги | `HandcartTerrainTests`: native Entity.move загруженной тележки по плитам и блокам, высокая стена | Полное испытание всех модовых лестниц и длительное движение по всему рельефу |
| Недоступный конец переправы | `unloadedRopeDestinationNeverLoadsChunksOrSpendsReservedCargo`: зарезервированный груз и прогресс сохраняются после reload; удалённый чанк остаётся незагруженным, forced-ticket не создаётся | Реальную выгрузку населённого чанка на публичном сервере |
| Работа крана с препятствием | Существующие `LogisticsTests`: груз остаётся на подвесе, препятствие приостанавливает движение, освобождение продолжает конечный заказ | Визуальное качество полного цикла при задержке сети |
| Границы работы инструментов | `ToolActionTests`: дерево костной мукой, старое дерево, отрицательная история поставленных брёвен, плоскость молота, остановка при поломке, повторная посадка серпом | Каждый сторонний мод защиты территорий и каждое модовое дерево |

Регрессии не регистрируют глобальные обработчики отмены разрушения ради единичного теста: такой обработчик без снятия загрязнял бы параллельные сценарии. Дополнительное разрушение инструментами использует штатный `ServerPlayerGameMode.destroyBlock`, а серп вызывает события BEFORE/AFTER и проверяет ограничения игрока. Совместимость с конкретными модами защиты проверяется отдельно.

Серверные mock-игроки не выдаются за два настоящих удалённых клиента. Клиентская сцена подтверждает интерфейсы, ввод и кадры одного клиента; сетевые задержки, обрывы реального соединения и удалённые камеры остаются отдельной приёмкой. Итог общего прогона записывается основным агентом после выполнения.
