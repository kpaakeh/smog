# Какие текстуры сейчас рисовать

**Рабочая папка: `src/main/resources/assets/smog/textures`.** В ней остаются только PNG актуальных материалов: `block/` и `item/`. Своей серы больше нет — используется ванильная.

- В `block/` лежат обычные и глубинные руды, блоки сырья/металлов, семь природных пород и текстуры жидкостей.
- В `item/` — сырьё, слитки/самородки/пластины там, где они зарегистрированы, пыль, дроблёная руда, осколки, куски неметаллов и вёдра.
- Боксит и редкоземельное сырьё не имеют выдуманных металлических слитков/самородков.
- Большинство файлов — 16×16. У жидкостей используются исходные ванильные полосы анимации (still — 16×512, flow — 32×1024); `.png.mcmeta` задаёт анимацию.

**`src/gametest/resources/...` рисовать сейчас не нужно:** там архивная графика тестовых механизмов и GUI для проверки сохранённых систем. Она не входит в обычный JAR.

Проверка актуальности:

```powershell
.\gradlew.bat generateContent
python tools/audit_textures.py
python tools/audit_textures.py --list
```

Аудит идёт от реально подключённых моделей блоков/предметов и жидкостей; показывает лишние и отсутствующие PNG. Он ничего не удаляет. Обычный `generate_textures.py` создаёт только недостающие файлы; `--force` перезаписывает рисунки. Генератор GUI при пустом каталоге машин пишет только в тестовые ресурсы.

## Ванильная основа

`python tools/generate_textures.py --force` перекрашивает текстуры из локального Minecraft 26.3 JAR; путь можно указать через `--minecraft-jar`. Слитки, самородки, сырьё и металлические блоки используют железные варианты. Пыль — redstone, дроблёная руда — glowstone_dust, осколки — flint. Руды используют вкрапления iron_ore поверх точного ванильного камня или глубинного сланца. Породы используют calcite, diorite, clay, amethyst_block, tuff и basalt_side. Вёдра сохраняют металлическую часть water_bucket; перекрашивается только вода. Жидкости используют ванильные water_still/water_flow/water_overlay с исходными кадрами и mcmeta. У нефти альфа 255, клиентский оттенок белый, чтобы избежать двойной окраски.

Предыдущие рисунки сохранены локально в `.gradle/material-art-before-vanilla-recolor/`; они не входят в мод.

## Медная мастерская 0.7.1

Единая текстура горячих кирпичных деталей — `block/refractory_bricks.png` (ванильные кирпичи, умеренно темнее/насыщеннее). Копии моделей берут материал из этого файла. UV сохраняют 16 пикселей на блок; генератор удаляет внутренние и совпадающие грани. Проверка: `python tools/audit_models.py`.

GUI `copper_workshop.png`, `slot.png`, `copper_progress_*`, `copper_lit_progress.png` собираются из исходных ванильных GUI сундука и печи. Расплавы используют перекрашенные ванильные анимации лавы; видимые поверхности в чашах — соответствующие кадры. `generate_copper_assets.py` обновляет модели и общий кирпичный/GUI-материал, а пользовательские отдельные иконки не перезаписывает.
