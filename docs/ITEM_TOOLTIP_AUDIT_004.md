# Аудит описаний предметов 0.0.4

Проверены все production `appendHoverText`, клиентские ItemTooltipCallback, регистрация компонентов и генератор ресурсов. Массового LORE у предметов нет.

| Источник | Итог |
|---|---|
| WorkshopControlItem: контроллеры, водяной привод и канатный анкер | Длинные инструкции убраны из тултипов. Рабочие подсказки интерфейса, сообщения взаимодействия и JEI сохранены. |
| RopeLinkItem: грузовой канат | Убраны две постоянные строки руководства. Сообщения привязки/отвязки работают при действии. |
| WorkshopCanisterItem | Сохранены вид жидкости и фактическое количество: это содержимое ёмкости, а не лишнее описание. |
| ModularToolItem / ToolPartItem | Сохранены характеристики, свойства и состав. Подписи значений и свойств разделены двоеточиями. |
| Остальные предметы и блоки | Дополнительных описаний из этих источников нет. Ванильные сведения о чарах, названиях и содержимом не удаляются. |

Ctrl открывает свойства, Alt — конструкцию. При одновременном нажатии Ctrl имеет приоритет: длинные два раздела не складываются в один выходящий за экран тултип. Внешний вид остаётся ванильным.
