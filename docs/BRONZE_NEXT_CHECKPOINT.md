## Обязательные ограничения

- Перед долгой работой и не реже раза в минуту запускать внешний check_limits.py. При 20% — только сохранение целого этапа: build -x check, commit, push; тесты в резерве запрещены. Проверять свежесть обоих каналов.
- Диапазон −512…512, 0 — остановка. Отдельного понижающего редуктора нет; старый ID bronze_reduction_gearbox означает большую шестерню.
- Не менять версию без прямой команды пользователя. Звук и мультиплеер отложены.
- Сохранять пользовательские незакоммиченные docs/README.md, BRONZE_AGE_CONTENT_SPEC.md, BRONZE_AGE_DESIGN.md, BRONZE_AGE_DESIGN_HANDOFF.md и docs/presentations/. Не добавлять их в коммит автоматически.
- Доводить выбранный блок полностью перед переходом к следующему; после одного блока не заканчивать всю работу, кроме границы лимита/прямой остановки.
