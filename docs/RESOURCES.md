# Стартовые ресурсы Smog

Активна только материальная база. Список генерации зафиксирован по последнему запросу: 13 руд, 8 неметаллических залежей, 2 подземных ресурса. Ванильные руды не заменяются. Новые ресурсы появляются в **новых чанках обычного мира**.

Namespace всех ID — `smog`. Есть каменный и глубинный варианты. У 11 металлических семейств зарегистрированы обычные 11 форм (руды, сырьё/блок сырья, слиток/блок, пыль, дроблёная руда, осколок, самородок, пластина).

У боксита и редкоземельной руды `product: "none"`: зарегистрированы семь сырьевых форм без выдуманных «бокситовых слитков» и «редкоземельных слитков». Для них не создаётся прямая плавка в металл. Алюминий, серебро, кобальт и висмут сохранены как обработанные материалы; отдельные руды для них сейчас не генерируются. Полноценное обогащение и извлечение металлов будет добавляться вместе с нужными эпохами.

## Нефть и рассол

| Ресурс | ID жидкости | Размер скопления | Попыток на чанк | Высоты |
|---|---|---:|---:|---|
| Нефть | crude_oil | 48 | 1 | -56…-8 |
| Минерализованный рассол | mineral_brine | 48 | 1 | -48…16 |

Генерируются реальные скопления источников жидкости внутри каменной породы; открытые к воздуху клетки отбрасываются. Есть источник, течение, анимированные текстуры и ведро для каждой жидкости. Источники конечны: бесконечное восполнение отключено. Нефть не входит в тег воды, рассол входит.

Это основа подземного ресурса, а не система скважин, геологических запасов или нефтепереработки. Механизмы добычи отложены. Хладагент сохранён как готовый материал и подземлёй не генерируется.

## Настройка и регистрация

Каталог: `src/main/content/smog.content.json`.

- `ores` — рудные семейства, `product` допускает `ingot`, `gem`, `none`.
- `deposits` — природный неметаллический блок + кусок + пыль.
- `metals` — обработанные металлы без собственного рудного семейства.
- `alloys` — обработанные сплавы; существующая сталь сохранена.
- `fluids` — типы жидкостей и вёдра; `water_like: false` отключает водный тег.
- `underground_resources` — генерация подземного скопления указанной жидкости.

`vein_size`, `veins_per_chunk`, `min_y`, `max_y` задают стартовый баланс. Высоты распределены равномерно; числа не гарантируют столько жил в каждом чанке. В одном скоплении не больше 64 блоков по настройке стандартной OreFeature. Все 23 placed-feature внедряются в биомы обычного мира.

После изменения регистраций перезапусти игру. Для недостающих PNG можно запустить `python tools/generate_textures.py`; готовые PNG уже включены. Обычный запуск сохраняет существующие рисунки. `--force` перезаписывает их.
