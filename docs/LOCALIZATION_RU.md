# Русские названия — 0.0.4

> Навигация 0.0.4: [полное руководство](GUIDE_0.0.4.md) · [точные данные каталога](CONTENT_REFERENCE_0.0.4.md) · [все JSON-рецепты](RECIPE_REFERENCE_0.0.4.md) · [оглавление](README.md). Датированные результаты проверок ниже относятся к своим ревизиям.

Нормализация применяется к итоговой локализации после объединения основного каталога, материалов инструментов и декоративных семейств. Исходники: tools/normalize_localization.py и tools/generate_decor.py. Результат формируется при generateContent, ручные изменения build/generated не нужны.

Правила:

- Для простого материала используется согласованное прилагательное: «Оловянный слиток», «Свинцовая пластина», «Медная кирка».
- Для сложного названия сплава сохраняется естественный родительный падеж: «Слиток нержавеющей стали», «Головка кирки из нержавеющей стали».
- Род детали учитывается отдельно: «Медная головка кирки», «Медное полотно пилы», «Верёвочное крепление». Отливка — «Отлитое медное полотно пилы».
- Сырая руда следует ванильной логике: «Рудное олово», «Рудный свинец». Вёдра — «Ведро расплавленной меди».
- Формы называются по назначению: «Керамическая форма для головки кирки», «Необожжённая форма для полотна пилы».
- Декор: «Известняковые кирпичи», «Полированный известняк», «Известняковая плита», «Ступеньки из известняковых кирпичей», «Замшелые известняковые кирпичи».
- В названиях предметов и блоков запрещены каталожные разделители «:» и « — ». Информационные предложения и подсказки сохраняют пунктуацию.

Отчёт по всем именам: build/review/localization-ru-audit.json. Проверка русских названий включена в серверный прогон. Дополнительно проверяется совпадение параметров форматирования с английскими строками.
