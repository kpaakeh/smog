# Текущий набор инструментов 0.0.3

По запросу пользователя набор заменён на десять составных инструментов: кирка, топор, пила, лопата, молот, мотыга, меч, катана, мачете, серп. Резец и киркомотыга больше не зарегистрированы. Ранние перечни относятся к предыдущему дизайну.

Каждый инструмент собирается из своей головки, совместимой рукояти и крепления, с необязательной обмоткой. Добавлены каменные и деревянные головки: их формование и сборка полностью неметаллического инструмента запускаются пустой рукой либо кнопкой изготовления на медной наковальне. Если в результате есть любая металлическая деталь, включая хомут или рукоять, нужен рабочий составной молот. Отдельный несоставной каменный рабочий молот и его крафт удалены. Первый молот можно сделать из трёх каменных материалов, деревянной рукояти и шнурового крепления без другого молота.

- Пила валит связанные брёвна с сохранённой меткой генерации дерева; поставленные игроком блоки не получают такую метку. Метки сохраняются в чанке, снимаются при установке блоков и обычной рубке. На действие установлен предел 256 брёвен, радиус 8 и высота 48. Старые деревья в уже созданных чанках без меток обрабатываются по одному блоку: определять происхождение по соседней листве небезопасно для построек.
- Молот добывает область 3×3×1 в плоскости выбранной грани. Каждый дополнительный блок проходит штатное разрушение игроком, проверку уровня, разрешений и расход прочности; блоки с BlockEntity исключены. Shift оставляет одиночную добычу. Этот же молот используется в мастерской.
- Меч — базовый клинок; катана быстрее и слабее, мачете медленнее и сильнее. Атрибуты зависят также от материала и рукояти; клинки входят в тег мечей.
- Серп по ПКМ собирает зрелые культуры в области 3×1×3 и сбрасывает их возраст к посеву. Поддержаны обычные посевы CropBlock, адский нарост и какао. Из дропа удерживается один посадочный предмет на каждое растение; без него операция пропускается. Незрелые растения не трогаются, износ учитывается за каждое собранное растение.

Все дополнительные разрушения используют серверную защиту от рекурсии и прекращаются при поломке инструмента. Пользовательские сохранения для испытаний не используются.
