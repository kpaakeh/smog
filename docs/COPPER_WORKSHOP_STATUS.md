# Медная мастерская — единый статус 0.0.4

Сводка по прямым решениям пользователя 2 ноября 2026. Она имеет приоритет над прежними примерами и датированными аудитами. Код, серверная регрессия и реальная игровая приёмка обозначают разные уровни подтверждения. База опубликованной0.0.3:108/108серверных GameTests; новые изменения0.0.4 требуют своего общего прогона, результат которого фиксируется в MODLOG.md. Фраза «есть тест» ниже не выдаёт ещё не выполненный новый сценарий за успешный.

## Обязательные изменения

- Ровно десять инструментов: кирка, топор, пила, лопата, молот, мотыга, меч, катана, мачете, серп. Резец и киркомотыга исключены.
- Единственная форма инструментального стержня — обычный `standard_handle`. Любые материалы подходящих деталей сочетаются между собой. Головка задаёт уровень добычи; стержень и крепление не дают скрытого повышения уровня.
- Полностью неметаллическое формование/сборка доступны без молота; любая металлическая деталь требует рабочего составного молота. Первый каменный молот собирается без другого молота.
- Тултипы разделяются на краткую сводку, свойства при Ctrl и конструкцию при Alt; цвета разделов отличаются от референса, поведенческие свойства используют цвета своих материалов. Клиентская проверка актуальной версии обязательна.
- JEI показывает десять примеров сборки вместо матрицы материалов. Примеры обработки ограничены по числу; эквивалентная оснастка меняется в слоте. Реальные операции наковальни и плавильни не ограничены демонстрационным материалом.
- Баланс и назначение инструментов задаются отдельными профилями; точные числа показываются из настоящих компонентов. Нельзя считать баланс доказанным одним числом характеристик.
- Пила должна поддерживать естественные деревья и выращенные костной мукой, сохраняя защиту поставленных брёвен. Тележка должна преодолевать малые уступы штатным движением, без телепортации через стены.

## Что сейчас не является условием приёмки

Пункты4–7 прежнего списка (прохождение3–5часов, общий тайминг и доля ожидания) пользователь исключил. Пункт34 (миграция старых миров) отложен; пункт35 (свой модпак) пользователь проверяет сам. Финальный milestone завершения эры пока рано вводить: сначала развивается её содержание. Пункт33 перешёл из общей проверки в конкретное исправление малых уступов тележки.

Слоты улучшений Tinkers, удалённые рельефы/резец, управляемая поздняя атмосфера и высокотемпературные цепочки не возвращаются как якобы незакрытые обязательные требования. Файл COPPER_AGE_ADDITIONAL_MECHANISMS.md остаётся каталогом предложений, а не поручением построить все тринадцать устройств.
