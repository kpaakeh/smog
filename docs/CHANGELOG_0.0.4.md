# Smog 0.0.4 — полировка Медной мастерской

- Новые тултипы инструментов и деталей: краткий вид, Ctrl для характеристик, Alt для состава. Собственная тёмная палитра с бирюзовой рамкой, цвета свойств по материалам, перенос длинных строк; лишние стандартные списки содержимого скрыты.
- Названия готовых инструментов показывают тип и материал головки.
- Оставлен один тип стержня для всех инструментов; материал головки, стержня, крепления и обмотки выбирается независимо.
- Перебалансированы урон, темп атаки, добыча и ресурс десяти классов инструментов. Таблица и материальные компромиссы: TOOL_BALANCE.md.
- JEI показывает десять примеров сборки и ограниченный набор примеров обработки вместо перебора комбинаций материалов. Варианты оснастки циклятся внутри карточки.
- Медные, железные и золотые концентраты доступны для обычного обжига и плавки в доменной печи в два канонических слитка.
- Пила поддерживает деревья, выращенные костной мукой, и старые естественные деревья без положительных меток через проверку корней и кроны. Отдельно сохраняются метки поставленных брёвен. Неизвестное старое строение, точно имитирующее естественное дерево, достоверно отличить невозможно.
- Загруженная тележка при тяге поднимается на полублоки и блоки штатным механизмом шага; высокая стена остаётся препятствием.
- Добавлены проверки независимых меню двух серверных игроков, однократной выдачи литья, сохранения груза и остановки переправы у незагруженного конца.
- Исправлены пять отсутствовавших текстур новых песчаных и металлических форм. Аудит:564PNG,0missing,0unused;58моделей,0ошибок.
- Синхронизированы документация и текущая матрица задач. Исключённые пользователем длительное прохождение, миграция старых миров и проверка его модпака не объявляются обязательными остатками.

Проверка:123/123серверных теста прошли, русский клиент с JEI завершился успешно, три вида тултипа просмотрены. Дополнительный test-only прототип двух настоящих клиентов не прошёл запуск peer: Java ProcessHandle не предоставил параметры процесса. Живой мультиплеер, сетевые задержки, полный звуковой аудит и полная визуальная матрица всех размеров/ракурсов пока не подтверждены. Опубликованный релиз0.0.3 не изменялся.


## Дополнение: полировка и декоративные семейства

- Добавлены210декоративных блоков для огнеупорного кирпича, известняка, флюорита, фосфорита, каолина, доломита, каменной соли и графита: полированные варианты, кирпичи, плитняк, резные, треснувшие и мшистые блоки, ступени, плиты и ограды. Новые текстуры16×16 — перекрашенные ванильные узоры; исходные блоки не перерисовывались.
- Нативные свойства ступеней, плит и оград: вода, соединения, коллизии и количество дропа. Добавлены крафты, камнерез, переводы и вкладка«Блоки».
- Формование и ремонт принимают альтернативные слитки изобщихc:ingots/<metal> беззаменыванильныхканоническихвыходов. Самородки, блоки и сырая руда не считаются одним слитком.
-18ремесленных рецептов принимают ванильные теги досок, деревянных заборов, камня, шерсти и песка. Стоимость волоконной обмотки согласована с её материалом.
- Проверены SilkTouchдополнительной добычи молотом, сохранение соседнегоBlockEntity, конечность заказа крана при постоянном редстоуне, сохранение/возобновление зарезервированного груза.
- Исправлены высота деталей на медной наковальне, затемнение частично залитого горячего металла, перенос длинных названий без пробелов.
- Звуковой и сетевой этапы отложены поуказаниюпользователя; тестовый сетевой прототип вынесен из активного кода.
